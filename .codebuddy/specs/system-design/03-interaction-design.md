## 一、设计系统

### 1.1 视觉风格

采用深色科技大屏风（基于参考样式 + 设计系统推荐）：

| 维度 | 规格 |
|------|------|
| 风格 | Dark Mode (OLED) — 深色高对比、科技感、数据可视化优先 |
| 背景 | 深蓝黑渐变 #050B13 → #07111D + 网格线叠层(58px) |
| 主色 | 青蓝 #2FD7FF（科技感主色） |
| 辅色 | 蓝 #3D8CFF、绿 #34DF9A、琥珀 #FFB33D、红 #FF5C6D、紫 #B56CFF |
| 文字 | 主文 #E6F6FF、次文 #79A3BF、弱文 #5A7A92 |
| 面板 | 半透明 rgba(9,25,41,0.86) + 青蓝描边 rgba(91,183,255,0.22) |
| 字体 | 标题/数字 Fira Code、正文 PingFang SC / Microsoft YaHei |
| 图标 | lucide-react（24x24 默认），禁止使用 emoji |
| 效果 | 微光 text-shadow 0 0 10px、扫描线、平滑过渡 150-300ms |

### 1.2 色彩语义

| 语义 | 色值 | 用途 |
|------|------|------|
| 正常/在线 | 绿 #34DF9A | 设备在线、任务正常、指标ok |
| 作业/进行中 | 青 #2FD7FF | 当前作业、进行中任务 |
| 警告/低电量 | 琥珀 #FFB33D | 低电量告警、warn 指标 |
| 故障/危险 | 红 #FF5C6D | 故障、急停、critical 告警 |
| 信息/辅助 | 蓝 #3D8CFF | 普通信息、info 告警 |
| 特殊/里程碑 | 紫 #B56CFF | 里程碑、特殊标记 |
| 待机/灰 | 灰 #687988 | 待机设备、灰显 |

### 1.3 布局规范

- 大屏分辨率：设计基准 2357x1248，支持缩放适配
- 栅格：58px 网格背景叠层
- 面板圆角：8px
- 间距：面板间距 12-16px，内部 padding 12-14px
- 字号层级：标题 20px / 面板标题 14px / 正文 13px / 标签 11px / 大数字 28-36px

### 2.4 左栏面板

#### ① 各类机器人使用数量（环形图+柱状图）

- 环形图展示各类型机器人当前投入使用数量占比
- 类型：AGV运输车、挖掘机、吊车、砌筑机器人、巡检机器人
- 图例：类型名 + 数量 + 占比
- 交互：悬停高亮+tooltip；点击扇区→甘特图筛选对应设备类型的任务

#### ② 土方资源负载（条形图）

横向条形图，每条：名称 + 负载条（0-100%）+ 数值
- 项目：挖机、渣土车队、测量班组、喷淋降尘、夜间照明、安全巡检
- 颜色：负载<70%绿、70-90%琥珀、>90%红

#### ③ 施工阶段总览（进度条）

7阶段纵向列表，每行：阶段名 + 进度条（青蓝渐变，显示百分比）+ 状态
- 进行中：高亮闪烁
- 已完成：绿色100%
- 未到达：灰显，仅显示大进度
- 交互：点击已完成阶段→甘特图切换历史视图；点击未到达→提示"该阶段尚未开始"

## 六、WebSocket 数据驱动交互

### 6.1 数据流

```
后端 WebSocket 推送
    │
    ▼
前端 api-client/ws 接收
    │
    ▼
Zustand store 更新（批量更新避免频繁渲染）
    │
    ├─→ PM端各面板订阅对应数据
    └─→ O&M端各面板订阅对应数据
```

### 6.2 频道订阅

| 频道 | PM端订阅 | O&M端订阅 |
|------|---------|----------|
| devices | KPI在线率、机器人数量、资源负载 | 设备分布环形图、3D场景设备标记、底部卡片 |
| tasks | 甘特图任务条、KPI任务数、待办列表 | 设备卡片当前任务 |
| alerts | 实时事件流 | 告警列表、实时日志 |
| pointcloud | - | 3D场景点云渲染 |
| events | 实时事件流 | 实时日志 |
| estop | 急停遮罩显示 | 急停遮罩显示+恢复按钮 |
| script | 阶段切换刷新 | 阶段切换刷新 |

### 6.3 性能优化

- devices 频道 1Hz 推送，前端批量更新（避免每台设备单独渲染）
- pointcloud 频道 5Hz 推送，前端用 BufferGeometry 直接更新 points
- Zustand 使用 selectors 避免不必要的 re-render
- 3D场景设备标记用 instancedMesh 优化（20-100个标记）
