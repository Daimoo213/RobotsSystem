## 一、设计原则

> **以实际应用为主，不以演示为主。**
> 系统全天自动运行执行任务，用户在运行过程中进行监控、决策、干预与复盘。

---

## 二、用户角色与职责

### 2.1 PM（项目经理）

**核心职责**：项目管理与施工指挥——决定"做什么、为什么做、做得怎样"。

| 职责类别 | 具体内容 |
|---------|---------|
| **项目需求观察** | 关注施工目标、工期要求、资源约束、上级指令，理解项目当前需求 |
| **施工任务发布** | 根据项目需求编制施工任务，设定工序、优先级、目标点位、适配设备类型 |
| **项目阶段管理** | 管理施工阶段推进，切换阶段，监控阶段完成度，处理跨阶段任务 |
| **施工进度监控** | 监控甘特图、KPI、完成趋势，掌握整体态势 |
| **施工结果观察** | 查看任务完成情况、质量检测结果、进度偏差，评估施工效果 |
| **任务干预** | 改派、插单、暂停、调整优先级 |
| **报表与复盘** | 导出报表，向上级汇报，项目复盘 |
| **应急响应** | 应急急停 |

### 2.2 O&M（运维人员）

**核心职责**：设备监测与运维保障——保障"设备正常运行、异常及时处置"。

| 职责类别 | 具体内容 |
|---------|---------|
| **设备监测** | 持续监测设备在线状态、健康度、位姿、电量、任务执行情况 |
| **异常处置** | 响应故障/低电量/路径冲突告警，远程处置或标记维修 |
| **运维操作** | 执行8项快捷指令（自检/充电/模式切换/诊断/备份/升级/网络检测/巡检） |
| **设备控制** | 暂停/恢复/重置/急停/恢复 |
| **3D场景监控** | 通过3D场景直观监控设备集群运行态势 |
| **应急响应** | 触发急停、执行急停恢复 |

### 2.3 角色协作关系

```
PM 侧（项目决策层）                O&M 侧（设备执行层）
─────────────────────              ─────────────────────
观察项目需求                        监测设备状态
    │                                   │
    ▼                                   ▼
发布施工任务 ──→ 系统自动调度 ←── 设备执行任务
    │              │   │                  │
    │              │   └──告警──→ O&M 处置异常
    │              │                       │
    ▼              ▼                       ▼
监控进度 ←── 实时反馈 ←── 设备状态上报
    │                                   │
    ▼                                   ▼
观察施工结果                         确认设备恢复
    │                                   │
    ▼                                   ▼
阶段管理 / 复盘                      运维记录
```

**关键协作点**：
- PM 发布任务 → 系统自动调度 → O&M 监测设备执行
- 系统告警 → O&M 处置 → PM 感知进度影响
- PM 阶段切换 → 通知 O&M 确认设备就绪
- 应急急停：两端均可触发，仅 O&M 可恢复

## 三、核心用户场景（10个）

### 场景一：施工任务发布（PM 主导）⭐ 新增

**应用背景**：PM 根据项目需求，向系统发布施工任务，由系统自动调度执行。

**触发**：PM 识别到新的施工需求（如接到新工序指令、阶段推进需要、上级临时要求）。

**PM 流程**：
1. PM 观察项目需求，确定需要执行的施工工序（如"基坑土方清运"）。
2. PM 在 PM 端打开"任务发布"面板（右栏待办任务区"+ 新增"或独立入口）。
3. 填写任务信息：
   - 选择工序（从29项工序中选择）
   - 设定目标施工点位（从地图点位中选择）
   - 设定优先级（默认按工序优先级体系，可手动覆盖）
   - 指定适配设备类型（如挖掘机，或留空由系统匹配）
   - 设定预估工期
   - 设置前置依赖任务（可选，构建DAG）
4. PM 提交任务 → 后端创建任务记录 → 加入调度DAG。
5. 调度引擎下个 tick 自动分配设备 → 任务进入执行。

**PM 端反馈**：
- 甘特图出现新任务行，显示在对应时间位置。
- KPI"进行中任务数"+1。
- 实时事件流显示："新任务 T-xxx 已发布，已分配至 EX-02"。

**约束校验**：
- 系统校验任务前置依赖是否满足（DAG 依赖）。
- 系统校验目标点位是否在禁行区（安全约束）。
- 系统校验适配设备类型是否有可用设备（资源约束）。
- 若校验失败 → 返回错误提示给 PM。

**关键验证点**：
- 任务发布后是否自动进入调度？
- DAG 依赖与安全约束是否正确校验？

---

### 场景二：项目阶段管理（PM 主导）⭐ 新增

**应用背景**：PM 管理施工阶段的推进、监控、切换与复盘。

**子场景 2a：阶段进度监控**
1. PM 在 PM 端左栏"施工阶段总览"查看 7 大阶段进度条。
2. 当前阶段高亮显示，已完成阶段显示 100%，未到达阶段灰显。
3. PM 观察当前阶段完成度，判断是否满足推进条件。

**子场景 2b：阶段切换**
1. 当前阶段任务全部完成（或满足切换条件）→ PM 在顶部下拉选择下一阶段。
2. 后端执行阶段切换：
   - 当前阶段未完成任务标记为"跨阶段延续"。
   - 加载新阶段的任务 DAG 子集。
   - 设备重新分配。
3. 两端大屏同步刷新：
   - PM 端甘特图加载新阶段任务行。
   - O&M 端 3D 场景加载新阶段点位与模型配置。
4. PM 通知 O&M 确认设备就绪。

**子场景 2c：阶段完成度展示**
1. PM 可切换查看任意阶段的完成度状态（0%/30%/60%/100%）。
2. 用于向上级汇报或向参观者展示建设进度。
3. 各阶段完成度数据来自 TimescaleDB 任务完成统计。

**子场景 2d：跨阶段复盘**
1. PM 在甘特图切换到"月/季度"视图。
2. 浏览已完成阶段的历史任务执行情况。
3. 导出报表选择时间范围 → 下载 Excel 进行复盘。

**关键验证点**：
- 阶段切换是否平滑？跨阶段任务是否正确处理？
- 完成度数据是否准确？

### 场景三：常规施工调度（系统自动 + 双端监控）

**应用背景**：系统全天自动运行，持续调度设备执行任务。

**系统自动流程**：
1. 调度引擎按 DAG 依赖关系，将可执行任务分配给适配设备。
2. 设备接收派单 → 移动到目标点 → 执行工序 → 上报进度。
3. 任务完成 → 自动解锁后继任务 → 继续调度。
4. 全程遥测数据实时推送到两端大屏。

**PM 监控（观察进度与结果）**：
1. 甘特图实时更新任务进度条，今日线标记当前时间。
2. KPI 指标条实时刷新（总体进度、进行中任务数、资源负载率、延期风险数）。
3. 完成趋势折线图实时绘制（计划/实际/预测三线）。
4. 摄像头视角浮窗显示 AI 识别结果（模拟数据）。
5. 右栏实时事件流滚动显示闭环事件。
6. PM 观察施工结果：哪些任务完成了、质量如何、进度是否偏差。

**O&M 监测（监测设备）**：
1. 3D 场景实时显示设备位置、移动路径、作业状态。
2. 设备状态分布环形图实时变化（待机/作业/移动/充电数量）。
3. 底部设备卡片条实时更新设备状态与体检指标。
4. 左栏实时运行日志滚动显示事件。
5. 右栏集群协同拓扑显示设备协作关系。
6. O&M 持续监测：设备是否在线、电量是否正常、是否有异常移动。

**关键验证点**：
- 调度是否按 DAG 依赖正确推进？
- 双端监控数据是否实时同步？

### 场景四：设备故障处置（O&M 主导，PM 协同）

**应用背景**：设备突发故障，O&M 快速处置，PM 感知进度影响。

**O&M 处置流程**：
1. O&M 端告警列表出现红色告警："EX-02 设备故障，已停止响应"。
2. 底部设备卡片 EX-02 状态变为"故障报警"，体检指标显示 fail。
3. O&M 点击 EX-02 卡片下钻 → 查看故障详情（故障时间、历史告警、最后位置、轨迹回放）。
4. O&M 评估故障：
   - 可远程恢复 → 执行"重置"命令。
   - 需现场处理 → 标记为"维修占用"，设备退出调度池。

**系统自动响应**：
1. 调度引擎检测到故障 → 当前任务自动回退到队列 → 重新分配。
2. 告警引擎推送通知到 PM 端。

**PM 协同**：
1. PM 端甘特图：故障设备任务行设备标签更新为新设备，进度继续。
2. PM 端事件流："任务 T-005 已从 EX-02 改派至 EX-03"。
3. PM 评估进度影响，决定是否调整后续任务排期。

**关键验证点**：
- 故障设备任务是否正确回退并重新分配？
- O&M 下钻详情是否完整？

---

### 场景五：低电量与充能调度（系统自动 + O&M 干预）

**应用背景**：设备电量下降，系统错峰调度充电，O&M 可干预。

**系统自动流程**：
1. 能耗维保模块监控设备电量。
2. 电量低于阈值（20%）→ 该设备对后续任务投标降权。
3. 设备空闲间隙 → 自动派发充电任务 → 移动到充电桩 → 充满恢复待命。

**O&M 干预**：
1. O&M 在能耗视图查看所有设备电量分布，预判充电需求。
2. O&M 可点击"强制充电"立即派发充电任务（不等空闲）。
3. O&M 监测充电进度，确认设备恢复正常。

**PM 感知**：
1. PM 端 KPI"资源负载率"反映可用设备变化。
2. PM 端甘特图显示充电设备暂时不可用。

**关键验证点**：
- 错峰充能是否避免集中断电？
- 强制充电是否立即生效？

---

### 场景六：路径冲突与碰撞避免（系统自动 + O&M 监控）

**应用背景**：多设备路径交叉，系统自动避碰。

**系统自动流程**：
1. 碰撞联锁模块实时检测设备位姿。
2. 进入安全距离 → 后车减速/停车 → 重规划路径 → 解除冲突恢复移动。

**O&M 监控**：
1. 3D 场景：冲突设备红标闪烁，路径线变更可视化。
2. 实时日志："AGV-01 与 AGV-02 路径冲突，AGV-02 已避让"。
3. O&M 在安全视图查看电子围栏与避让区域。

**关键验证点**：
- 碰撞联锁是否及时触发？
- 重规划路径是否合理？

---

### 场景七：任务干预与优先级调整（PM 主导）

**应用背景**：PM 根据现场情况临时调整任务安排。

**子场景 7a：任务改派**
1. PM 观察到某任务进度缓慢或设备不适配。
2. PM 在甘特图点击任务行 → 弹出详情 → "改派" → 选择目标设备 → 确认。
3. 后端更新分配 → 原设备释放 → 新设备接管。

**子场景 7b：紧急插单**
1. 现场临时需要增加任务（如接到安全巡检通知）。
2. PM 新建任务 → 设置优先级=紧急 → 系统优先调度。
3. 甘特图出现新任务行，置于高优先级位置。

**子场景 7c：任务暂停与恢复**
1. PM 暂停某任务（如外部原因需暂停浇筑）。
2. 后端通知设备暂停 → 任务状态 paused。
3. 原因解除后 PM 点击"恢复" → 任务继续。

**关键验证点**：
- 改派后原设备是否正确释放？
- 紧急插单是否正确抢占优先级？

---

### 场景八：应急急停与恢复（PM 或 O&M 触发，O&M 恢复）

**应用背景**：突发安全事件，需立即停止所有设备。

**触发（PM 或 O&M 均可）**：
1. 触发方点击"急停" → 二次确认。
2. 后端设置 estop:status=active → Redis 广播。
3. 所有设备立即停止 → 两端大屏全局急停态（红色闪烁）。

**恢复（仅 O&M）**：
1. O&M 确认现场安全 → 点击"恢复"。
2. 后端校验角色=om → 清除急停 → 广播恢复。
3. 设备恢复运行 → PM 端提示"系统已恢复"。

**PM 触发限制**：PM 触发后无法自行恢复，必须通知 O&M。

**关键验证点**：
- 急停是否立即生效（< 1s）？
- PM 触发后是否确实无法自行恢复？

### 场景九：运维操作与设备管理（O&M 主导）

**应用背景**：O&M 日常设备管理与运维操作。

**8项运维快捷指令**：

| 指令 | 应用场景 | 效果 |
|------|---------|------|
| 设备自检 | 开工前/故障排查 | 全量诊断体检指标（连/定/电/任/安） |
| 强制充电 | 电量紧张/预防性 | 立即派发充电任务（路径最短） |
| 模式切换 | 调试/手动接管 | 切换自动/手动模式 |
| 系统诊断 | 异常定位 | 诊断系统各模块状态 |
| 数据备份 | 定期备份 | 实时同步数据到备份存储 |
| 固件升级 | 设备维护 | OTA 分发固件 |
| 网络检测 | 通信异常 | 检测信号覆盖与连接质量 |
| 安全巡检 | 围栏校验 | 校验电子围栏与安全区域 |

**设备状态筛选**：O&M 点击筛选芯片（作业/移动/待机/充电/故障/维修占用）→ 3D 场景与卡片条同步筛选。

**单设备下钻**：O&M 点击设备卡片 → 详情面板（设备信息/当前任务/位姿/电量/体检指标/历史告警/轨迹回放）。

**关键验证点**：
- 运维指令是否仅 O&M 可触发？
- 下钻详情是否完整？

---

### 场景十：施工结果观察与报表复盘（PM 主导）⭐ 新增

**应用背景**：PM 需要观察施工结果，评估效果，向上级汇报或进行项目复盘。

**PM 流程**：
1. PM 在 PM 端观察施工结果：
   - 甘特图查看已完成任务（绿色标记）与延期任务（红色标记）。
   - KPI 指标条查看总体进度、AI 识别合规率。
   - 完成趋势折线图对比计划与实际偏差。
   - 摄像头视角查看现场实况。
2. PM 导出报表：
   - 选择报表类型（设备/任务/告警/能耗/进度 5 大维度）。
   - 选择时间范围（日/周/月/季度/自定义）。
   - 选择筛选条件（标段/设备类型/工序）。
   - 下载 Excel 多 Sheet 报表。
3. PM 进行复盘：
   - 分析设备利用率是否达标。
   - 分析任务延期原因。
   - 分析告警闭环率。
   - 分析能耗效率。
   - 据此优化后续施工计划与任务发布策略。

**关键验证点**：
- 报表数据是否准确全面？
- 复盘指标是否支撑决策？

## 五、用户旅程图

### 5.1 PM 端完整旅程（项目全周期）

```
[项目需求观察]
  关注施工目标/工期/资源/上级指令
    │
    ▼
[施工任务发布] ──→ 系统自动调度执行
    │                    │
    │              ┌─────┴─────┐
    │              ▼           ▼
```

## 六、施工阶段定义

系统支持 7 大施工阶段，PM 可切换管理：

| 阶段 | 主要工序 | 完成度展示意义 |
|------|---------|---------------|
| 土方开发 | 场地平整、基坑土方清运、渣土外运 | 展示土方调度能力 |
| 基础施工 | 桩基施工、基坑支护 | 展示基础工程调度 |
| 主体施工 | 钢筋绑扎、模板安装、混凝土浇筑、预制构件吊装、楼层砌筑 | 展示主体施工协同 |
| 机电安装 | 管线安装、桥架安装、电缆敷设 | 展示机电穿插施工 |
| 装修施工 | 内墙抹灰、墙面喷涂、地坪打磨、瓷砖铺贴、吊顶安装 | 展示装修多工序并行 |
| 室外景观 | 室外道路、绿化、管网 | 展示收尾阶段 |
| 竣工 | 质量检测、场地文明规整 | 展示验收阶段 |

**切换方式**：PM 端顶部下拉选择施工阶段 → 系统加载对应阶段任务集与配置。

## 七、报表指标设计

### 7.1 设备维度
| 指标 | 说明 |
|------|------|
| 设备运行时长 | 每台设备时间范围内总运行时长 |
| 设备利用率 | 工作时长/总时长 |
| 设备故障率 | 故障时长/总时长 |
| 设备故障次数 | 故障发生次数 |
| 平均故障恢复时间 | MTTR |
| 充电次数与时长 | 充电频次与总时长 |
| 设备行驶里程 | 移动总距离 |

### 7.2 任务维度
| 指标 | 说明 |
|------|------|
| 任务完成率 | 已完成/总任务数 |
| 任务平均完成时长 | 实际vs预估 |
| 任务延期率 | 延期/总数 |
| 任务改派次数 | 改派频次 |
| 任务插单次数 | 紧急插单频次 |
| 按工序完成统计 | 29项工序各自完成数与平均时长 |

### 7.3 告警维度
| 指标 | 说明 |
|------|------|
| 告警总数与分级 | critical/warning/info |
| 告警分类统计 | offline/timeout/low_battery/path_conflict/boundary |
| 平均告警响应时间 | 产生到确认 |
| 告警闭环率 | 已解决/总告警 |

### 7.4 能耗维度
| 指标 | 说明 |
|------|------|
| 总能耗 | 所有设备总耗电量 |
| 按设备类型能耗 | 分类能耗 |
| 充电总时长 | 错峰充电统计 |
| 能耗效率 | 完成任务数/总能耗 |

### 7.5 进度维度
| 指标 | 说明 |
|------|------|
| 总体进度百分比 | 当前完成度 |
| 按阶段进度 | 7大阶段各自完成度 |
| 按标段进度 | 各标段完成度 |
| 计划 vs 实际偏差 | 进度提前/延后天数 |
| 关键里程碑达成率 | 里程碑节点达成情况 |

### 7.6 报表导出格式

- **Excel**：多 Sheet（设备/任务/告警/能耗/进度），每 Sheet 一个维度。
- **时间范围**：支持按日/周/月/季度/自定义。
- **筛选**：支持按标段/设备类型/工序筛选。
